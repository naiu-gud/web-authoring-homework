Summer coding garden

Welcome to a bright and leafy web space.

Greenfield Coding Club is a friendly place for beginners and curious makers. Here we learn step by step, grow ideas together, and turn small experiments into websites we can proudly share.

This page is designed with a fresh green summer vibe, inspired by leaves, sunshine, and the calm feeling of working in a garden full of ideas.

A seasonal theme

A page that feels softer and less stiff.

Instead of a plain classroom page, this layout tries to feel like a small summer garden. The colors, wording, spacing, and later the CSS decorations will make the page look more relaxed, lively, and charming.

In Session 5, the most important thing is not only beauty, but also using semantic HTML correctly: header, nav, main, section, aside, and footer all have clear jobs in the layout.
